# 「统计」App 方案设计（自用 · Android）

> 状态：方案讨论稿 v0.1 · 2026-10-10
> 目标设备：iQOO Neo 10（OriginOS / Android 15）
> 开发方式：WorkBuddy 开发，用户装机验证，按里程碑交付

## 1. 项目定位

- 自用单机应用：不上架、不做隐私合规、不做多用户、不做云同步；
- 保留数据导出/导入功能（本地数据丢失无法恢复，此功能成本低、价值高）；
- 核心功能：**每日任务打卡** + **积分统计**；
- 远期可选：手机应用使用时间统计（可选增强 + 降级设计，最后做）。

## 2. 功能蓝图

### 2.1 任务系统

- **周期类型**：每日 / 每周 / 每月 / 每年；
- **统一周期模型**：周期 + 目标次数 + 提醒计划
  - 目标次数 = 1 → 固定型任务（如"每周六打扫"）
  - 目标次数 > 1 → 计数型任务（如"每周锻炼 3 次"、"本月读 2 本书"）
- **到点行为**（二选一）：
  - `提醒完成`：到点按设定级别发出提醒，等待手动打卡；
  - `自动完成`：到点静默打勾并自动加积分，不打扰；支持提前手动完成、完成后撤销。
  - （V1 约束：自动完成仅用于固定型任务；与计数型的组合规则待定）
- **提醒级别**（四档强度 + 可叠加震动）：

| 级别 | 效果 | 技术实现 | 额外权限 |
|---|---|---|---|
| ① 静默 | 仅通知栏，无声无横幅 | 低优先级通知渠道 | 无 |
| ② 普通 | 提示音 + 通知栏 | 默认优先级渠道 | 无 |
| ③ 横幅 | 屏幕顶部弹出（类微信） | 高优先级渠道（heads-up） | 无 |
| ④ 闹钟 | 全屏 + 铃声 + 震动，锁屏可见 | setAlarmClock + 前台服务 + 全屏 Intent | 精确闹钟、全屏通知 |
| ＋震动 | 任意级别可叠加，自定义节奏 | VIBRATE（安装即得） | 无 |

- **完成操作**：手动勾选 / 撤销（扣回积分）/ 补打卡（可指定日期）；
- **任务管理**：新建、编辑、启用/停用、删除、归档。

### 2.2 积分系统

- **积分分类**：用户自建分类（名称 + 颜色），如 学习 / 运动 / 家务；统计图配色取自分类；
- **任务计分**：任务绑定一个分类 + 分值；完成一次得一次分；
- **积分流水**：每次得分/扣分都记流水（支持负值）；
  - 撤销打卡 → 补一条负流水（不删历史）；
  - 手动调整 → 提供"补加/扣减 N 分"入口；
- **V1 约束**：任务单分类；表结构预留"一次打卡多条流水"的扩展能力。

### 2.3 统计系统（核心，尽可能完善）

页面结构（自上而下）：

1. **时间范围切换**：日 / 周 / 月 / 年；
2. **概览卡片**：总积分 + 环比（较上期）、任务完成率、连续打卡（全局 streak）；
3. **分类占比 · 环形图**：各积分类别构成；
4. **积分趋势 · 堆叠柱状图**：按时间桶 × 分类着色；
5. **任务排行 · 横向条形**：得分或完成次数 Top；
6. **打卡日历 · 热力图**：一年一屏，深浅表示活跃度；
7. **积分明细列表**：按分类 / 按天展开流水。

**统计口径**（先定死，避免数字矛盾）：

- 日界线可配置（默认 00:00，可设 04:00 等，熬夜党友好）；
- 周起始日默认周一（可配置）；
- 完成率：固定型 = 已完成/应完成；计数型 = 本期完成次数/目标次数；
- 环比：自动对比上一期；
- streak 两套：全局"连续活跃天数" + 每任务自己的连续天数。

## 3. 技术选型

| 关注点 | 选型 | 说明 |
|---|---|---|
| 语言 / UI | Kotlin + Jetpack Compose + Material 3 | 动态取色、深色模式 |
| 导航 | Navigation Compose（type-safe） | 单 Activity |
| 架构 | MVVM：ViewModel + 不可变 UI State + Flow | 单模块轻分层（data / ui） |
| 依赖注入 | Hilt | 标准方案 |
| 数据库 | Room + Flow | 任务、打卡、分类、流水四表 |
| 时间处理 | java.time（LocalDate / LocalTime） | minSdk 31 原生支持 |
| 调度 | AlarmManager + BroadcastReceiver + 前台服务 | 精确闹钟核心 |
| 图表 | Vico（柱状/折线）+ 自绘 Canvas（环形/热力图/进度） | Compose 生态首选 + 完全可控 |
| 构建 | Gradle KTS + Version Catalog | minSdk 31 / targetSdk 35 |

**架构分层**：

```
界面层（Jetpack Compose + Material 3）
  任务列表 · 统计图表页 · 设置页 · 打卡交互
        ↓
业务层（MVVM：ViewModel + Repository）
  任务仓库 · 积分仓库 · 统计聚合 · 提醒调度器
        ↓
数据与系统层
  Room 本地数据库 · AlarmManager · 通知/震动/前台服务 · 开机自恢复
```

## 4. 数据模型

四张核心表（Room）：

**Task（任务）**

| 字段 | 类型 | 说明 |
|---|---|---|
| id | Long PK | |
| name / note | String | 任务名 / 备注 |
| periodType | Enum | DAILY / WEEKLY / MONTHLY / YEARLY |
| periodTarget | Int | 目标次数（1 = 固定型） |
| remindPlan | JSON | 提醒计划（星期几 / 几号 + 时刻） |
| triggerAction | Enum | REMIND（到点提醒）/ AUTO_COMPLETE（到点自动完成） |
| remindLevel | Enum | SILENT / NOTIFY / BANNER / ALARM |
| vibrate | Bool | 附加震动 |
| categoryId | FK | 积分类别 |
| points | Int | 完成一次得分 |
| enabled / archivedAt | Bool / Long? | 状态 |

**CheckIn（打卡记录）**

| 字段 | 类型 | 说明 |
|---|---|---|
| id | Long PK | |
| taskId | FK | |
| periodKey | String | 周期归属键（见下表） |
| completedAt | Long | 完成时间 |
| source | Enum | MANUAL（手动）/ AUTO（自动完成） |
| revoked | Bool | 撤销标记 |

**PointsCategory（积分类别）**：id、name、color、sortOrder。

**PointsRecord（积分流水）**：id、categoryId FK、checkInId FK?、value（可负）、createdAt、note?。

**periodKey 规则**：

| 周期 | 示例 | 用途 |
|---|---|---|
| 每日 | `2026-10-10` | 当天是否完成 |
| 每周 | `2026-W41` | 本周 2/3 次、历史周回看 |
| 每月 | `2026-10` | 本月完成 N 次 |
| 每年 | `2026` | 年度进度 |

**核心规则**：总积分 = 流水求和；撤销不删记录、记负流水；补卡按打卡日期归属；统计全部为聚合查询（SUM / GROUP BY），无预计算表。

## 5. 提醒系统关键技术点

1. **API 分工**：低三档用 `setExactAndAllowWhileIdle()`（精确、不占状态栏）；闹钟档用 `setAlarmClock()`（最高保证，状态栏显示闹钟图标，仅用于闹钟级）；
2. **精确闹钟权限**：`USE_EXACT_ALARM`（Android 13+ 自动授予，自用无需审核）；检测失败时降级引导 `SCHEDULE_EXACT_ALARM`；
3. **全屏通知权限**：Android 14+ 需用户在设置中手动授予 → 由"权限体检"页引导；
4. **开机/更新恢复**：监听 BOOT_COMPLETED 与权限变更广播，重新注册全部任务闹钟；
5. **闹钟档触发链**：闹钟触发 → 前台服务播放铃声 → 全屏 Intent 通知亮屏直达 → 震动同步；
6. **测试按钮**：设置页提供"测试提醒"，四级各触发一次，快速验证；
7. **权限体检页**：逐项检测（通知 / 精确闹钟 / 全屏通知 / 电池优化 / 自启动），一键跳转对应设置页。

## 6. 设备适配（iQOO Neo 10 · OriginOS）

| 项目 | 路径（以系统实际为准） | 备注 |
|---|---|---|
| 通知权限 | 首次启动运行时请求 | Android 13+ |
| 横幅通知 | 系统设置 → 通知 → 本应用 → 允许横幅 | 影响 ③ 横幅级 |
| 精确闹钟 | 设置 → 应用 → 特殊权限 → 闹钟和提醒 | Android 14+ 需授权 |
| 全屏通知 | 同上特殊权限列表内 | 影响 ④ 闹钟级 |
| 自启动 | i管家 → 应用管理 → 自启动 | vivo 特有 |
| 后台高耗电 | 设置 → 电池 → 后台耗电管理 → 允许 | vivo 特有 |

以上全部做成"权限体检"页的一键跳转，装机后两分钟配完。
